# 手势吉他

用摄像头识别双手动作，在浏览器里选和弦、上下扫弦，也可以用键盘演奏并录下歌声。
无需注册账号或连接后端；手势识别、吉他合成、录音和导出均在本机完成，摄像头画面和录音不会上传。
吉他使用程序化 Karplus–Strong 合成，无需下载吉他采样。

## 一、启动应用

### 获取项目

公开仓库：[lichman0405/gesture-guitar-web-dev-pack](https://github.com/lichman0405/gesture-guitar-web-dev-pack)。
可在仓库页面下载 ZIP 并解压，也可以用 Git 克隆：

```powershell
git clone https://github.com/lichman0405/gesture-guitar-web-dev-pack.git
cd gesture-guitar-web-dev-pack
```

### Windows 双击启动

1. 安装 Node.js 长期支持版，建议使用 22 或更新版本。
2. 双击项目根目录的 **Start-Guitar.cmd**。
3. 等待浏览器自动打开，保持终端窗口开启。按 **Ctrl+C** 可停止服务。

首次启动需要联网安装依赖，并在缺失时下载手部识别模型。启动脚本会自动准备依赖、应用手部识别运行环境补丁并检查模型。
默认地址为 `http://localhost:5173/`；端口被占用时会自动选择其他端口，请以终端显示或自动打开的地址为准。

### 命令行启动

在项目根目录打开终端，执行：

```powershell
npm ci
npm run dev
```

随后在 Chrome 或 Edge 中打开终端显示的本地地址。请使用 `localhost`，摄像头和麦克风需要浏览器允许的安全上下文。
`npm ci` 会自动执行安装后处理，为手部识别的 WASM 加载器应用必要补丁，请勿跳过。
如果提示缺少手部模型，先执行 `npm run fetch:model`，再重新启动。

## 二、先用键盘试弹

首页点击 **「键盘演奏」**，按 **1** 选择 C 和弦，再按 **↓** 听到扫弦声音。
不需要摄像头或麦克风即可试弹。需要修改音色或调性时，首页进入 **「设置」**，调整后点击 **「使用键盘演奏」**。

| 按键 | 操作 |
|---|---|
| 1–9、0 | 选择第 1–10 个手势和弦，随当前调性或自定义映射变化 |
| C、D、E、F、G、A、B | 直接选择对应大和弦，例如 C |
| Shift＋上述字母 | 选择对应小和弦，例如 Shift＋C 选择 Cm |
| ↓ / ↑ | 向下 / 向上扫弦 |
| Shift＋↓ / ↑ | 重扫 |
| Ctrl＋↓ / ↑ | 轻扫 |
| 空格 | 切换闷音 |
| R | 开始 / 停止录音 |
| P | 暂停 / 恢复节拍 |
| Esc | 停止录音，录音结束时同时停止节拍 |

快捷键只在演奏页生效；输入框、下拉框获得焦点时不会触发快捷键。输入完成后点击页面空白区域再试弹。

## 三、用摄像头演奏

1. 首页点击 **「开始演奏」**，选择惯用手、模式、和弦映射与音色，点击 **「继续」**。
2. 浏览器询问时允许摄像头访问。让双手完整出现在画面里，手心朝镜头，使用均匀的正面光照。
3. 摆好演奏姿势，扫弦手放在准备弹的位置，静止约 2.5 秒完成校准，然后自动进入演奏页。
4. 默认是 **左手选和弦、右手扫弦**。选择「左手扫弦」后则相反。摄像头预览是镜像，左右指你身体上的实际左右手。
5. 和弦手势保持约 0.2 秒，等待「当前和弦」更新，再用另一只手上下扫弦。

校准失败时，可以 **「重新校准」**，也可选择 **「使用默认参数继续」** 试弹，或 **「切换到键盘演奏」**。
改变坐姿、摄像头距离或演奏位置后，在演奏页点击 **「重新校准」**。录音和生成导出文件期间该按钮不可用。

### 十种固定和弦手势

默认 **C 大调** 的映射如下。换调后和弦会随调性改变；演奏页 **「手势怎么弹」** 显示当前的实际映射。

| 和弦手姿势 | 默认和弦 | 键盘 |
|---|---|---|
| 伸出食指 | C | 1 |
| 伸出食指＋中指 | Dm | 2 |
| 伸出食指＋中指＋无名指 | Em | 3 |
| 四指伸直，拇指收起 | F | 4 |
| 五指张开 | G | 5 |
| 竖起拇指，其余四指收起 | Am | 6 |
| 伸出小指，其余手指收起 | D | 7 |
| 伸出食指＋小指（摇滚） | E | 8 |
| 拇指＋食指张成 L，其余三指收起 | Cm | 9 |
| 拇指＋小指张开（电话） | A#（等同于 Bb） | 0 |

**C 与 Cm 的区别：**只伸食指选 C 时，拇指可以自然搭在弯曲的手指上；要选 Cm，请将拇指明确向手掌外侧张开，与食指形成 L。
**摇滚 E 的姿势：**食指和小指伸出，中指、无名指弯曲，拇指自然放置即可；无名指不必完全收紧。
五指张开时要让拇指也明显展开；竖拇指时则将其他四指收起。避免两只手互相遮挡或移出画面。

### 自然扫弦与闷音

扫弦手的拇指和食指可轻捏，像拿拨片一样。手腕在预览中的绿色区域附近连续上下摆动，每次换向都能扫弦，无须停顿或大幅挥动整条手臂。
黄色圆圈是追踪点，绿色边界来自校准后的扫弦区域。

- 轻扫经常没有声音：先确认「当前和弦」已选中，再适当提高 **「扫弦灵敏度」**。
- 手静止时也发声：适当降低灵敏度，或保持双手静止重新校准。
- 扫弦手完全握拳可闷音；轻捏拨片的姿势不会被当作闷音。

### 双手控制手势

两只手同时摆出下列姿势并保持，可触发控制。日常录音也可以直接点击按钮，操作更容易确认。

| 双手同时摆出的姿势 | 保持时间 | 操作 |
|---|---|---|
| 竖拇指 | 1.2 秒 | 启动预备拍与节拍器 |
| 握拳 | 1.5 秒 | 暂停 / 恢复节拍 |
| 拇指与食指成圈，其余三指伸出 | 1.5 秒 | 开始 / 停止录音 |
| 五指张开 | 2 秒 | 停止录音，录音结束时同时停止节拍 |

## 四、设置与显示模式

| 设置 | 用途 |
|---|---|
| 自由演奏 | 自己选择和弦与扫弦节奏 |
| 节奏引导 | 按指定扫弦节奏练习，演奏页提示下一次扫弦方向 |
| 歌曲练习 | 输入和弦进行，如 `C G Am F`，每小节一个和弦，按顺序循环练习 |
| 按调性分配 | 选择大调，自动为十种手势分配和弦 |
| 自定义和弦 | 从 24 个大小和弦中分别选择十种手势的和弦，也可设为未分配 |
| 速度、拍号、预备拍 | 调整节拍速度、4/4、3/4 或 6/8 拍号及开始前的预备拍 |
| 开启节拍器声音 | 控制节拍声是否可听；演奏页可启动或停止节拍器 |
| 吉他音色 | 钢弦木吉他、尼龙弦吉他、清音电吉他 |

和弦输入支持大和弦和小和弦，例如 `C`、`Am`、`F#`、`Bb`，用空格或逗号分隔；当前不支持七和弦、挂留和弦等扩展类型。
设置会保存在当前浏览器中。普通模式显示预览与帮助，表演模式突出大号和弦，调试模式显示每秒帧数、识别耗时、运算设备、两只手五指伸展程度与扫弦检测状态。

## 五、录音、试听和下载

1. 在演奏页点击 **「开始录音」**，或按 **R**。
2. 如需录下歌声，允许麦克风访问，等到显示 **「正在录制麦克风」** 后再开始唱。等待授权时仍可弹吉他；拒绝麦克风权限也能录制吉他。
3. 完成后点击 **「停止录音」**，等待本机生成导出文件，再在结果页试听混音。
4. 点击需要的下载按钮保存文件。可选择 **「再录一次」** 返回演奏页，或 **「结束并返回首页」** 释放设备。

| 下载按钮 | 文件内容 |
|---|---|
| 下载人声（WAV） | 麦克风录下的单独人声；没有采集到人声时不会提供 |
| 下载吉他（WAV） | 按演奏事件重新合成的吉他音轨 |
| 下载混音（WAV） | 吉他与人声混音；无麦克风时为吉他混音 |
| 下载演奏记录（JSON） | 和弦、扫弦、闷音、控制事件及本次演奏设置 |

文件名带有本次录音编号与 `.vocal.wav`、`.guitar.wav`、`.mix.wav` 或 `.performance.json` 后缀。
人声不会从扬声器实时回放，避免啸叫。麦克风授权延迟会计入混音对齐，录音前已选好的和弦也会保存在演奏记录中。
引导和歌曲练习录音结束后，还会显示扫弦命中、方向、节奏误差、和弦命中及各小节问题。

**离开结果页、刷新页面或关闭应用前，请先下载需要的文件。**录音文件不会自动长期保存到磁盘；「再录一次」后再次录音会替换上一份结果。

## 六、常见问题

| 现象 | 处理方法 |
|---|---|
| 摄像头权限被拒绝 | 在浏览器地址栏的网站权限中允许摄像头，刷新后重试；也可切换到键盘演奏 |
| 找不到摄像头或画面黑屏 | 检查设备连接，关闭其他占用摄像头的应用，确认访问的是本地地址 |
| 手势没有切换和弦 | 手心朝镜头，双手完整入镜且互不遮挡；调整正面光照，保持姿势片刻 |
| 食指被识别为 L | 让拇指自然贴近弯曲的手指；仅在要选 L 和弦时向外张开拇指 |
| 扫弦漏触发或乱触发 | 先选好和弦，重新校准演奏位置，再按前述方法调整扫弦灵敏度 |
| 没有声音 | 检查系统音量、浏览器是否静音、输出设备；先用键盘选 C 并按 ↓ 排查 |
| 没有人声文件 | 检查麦克风权限与输入设备；看到「正在录制麦克风」后再唱 |
| 识别慢或卡顿 | 在调试模式查看帧数和识别耗时；关闭占用资源的应用，检查浏览器硬件加速 |
| 部分导出失败 | 先下载其他可用文件和演奏记录，再重新录制后重试 |

手部识别启动时会自动比较可用运算设备，选择较快的一种。软件渲染环境中的速度与真实显卡可能不同。
真实人手与不同光照下的识别准确率仍需持续实测；调试面板可以帮助判断手指姿势是否被正确识别。

## 七、开发与验证

```powershell
npm run typecheck
npm run lint
npx vitest run
npm run build
npx playwright install chromium
npm run test:e2e
npm run test:soak
```

`npm run test:soak` 执行完整十分钟连续稳定性验证。自动化测试使用模拟摄像头与麦克风，不能替代真人识别体验。
生产构建完成后，可执行 `npm run preview` 预览，打开终端显示的地址。

Windows 受限环境下可将测试浏览器安装到工作区：

```powershell
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD/.cache/ms-playwright"
npx playwright install chromium
```

摄像头诊断：`node scripts/diag-real-camera.mjs`；识别线程诊断：`node scripts/diag-vision.mjs`；扫弦逐帧追踪：`npx tsx scripts/debug-strum.ts`。
实时摄像头、手势、音频和录音处理独立于 React 渲染循环。请保留识别线程看门狗、启动运算设备比较，以及安装后 WASM 补丁。

日常开发先在本地验证并提交；本项目已获得所有者明确授权，以公开仓库形式发布到 GitHub。
完整开发记录见 [DEVELOPMENT_LOG.md](DEVELOPMENT_LOG.md)，验收标准见 [docs/ACCEPTANCE_TESTS.md](docs/ACCEPTANCE_TESTS.md)，任务图见 [docs/TASK_DAG.md](docs/TASK_DAG.md)。
